# Manuscript: "Declared but Not Applied: County Size and Participation in Post-Disaster Hazard Mitigation after Tornadoes and Severe Storms"

This is a working manuscript for *Risk Analysis* (Original Research), anonymized for double-blind review. It is built from the latest small-county-gap results of the Tornedo project (`../tornado_mitigation/src/50–52`).

## Files

| Path | Content |
|---|---|
| `risk_analysis_manuscript.pdf` / `.tex` | Compiled manuscript and its source: title page, abstract and keywords, main text, statements, references, Tables 1–5, Figures 1–5, Supporting Information S1–S4 |
| `references.bib` | biblatex (APA) bibliography, DOI-verified |
| `tables/table_1–5.tex` | Generated by `scripts/make_tables_figures.py` |
| `appendix/` | `supplementary_material.tex` (input by the main file), Tables S1–S2 |
| `figures/figure_1–5.pdf` | Vector figures, generated by the same script |
| `scripts/` | All reproduction and verification scripts (below) |
| `audit/` | Provenance, reference-article analysis, literature matrix and coverage report, claim-to-source map, quality check, remaining tasks, build logs, page previews |

## Reproduce

Requires Python 3.13 with pandas, pyfixest, geopandas and matplotlib, plus MiKTeX or TeX Live with biber.

```
# 1. project pipeline (data and panels), in ../tornado_mitigation/src
py -3.13 43_download_redesign.py; py -3.13 44_spc_exposure.py; py -3.13 50_small_county_robustness.py
py -3.13 51_gap_mechanisms.py; py -3.13 52_gap_causal_tests.py
# 2. tables, figures, numbers
py -3.13 scripts/make_tables_figures.py
# 3. bibliography (Crossref) and checks
py -3.13 scripts/build_bib.py; py -3.13 scripts/prune_bib.py
py -3.13 scripts/check_claims.py; py -3.13 scripts/citation_coverage.py; py -3.13 scripts/word_count.py
# 4. compile
pdflatex risk_analysis_manuscript; biber risk_analysis_manuscript; pdflatex risk_analysis_manuscript; pdflatex risk_analysis_manuscript
```

Two notes on the rebuild:
- Re-running `build_bib.py` regenerates `references.bib` from Crossref, with the author and year fixes encoded in the script. Run `prune_bib.py` afterwards.
- A copy of the final PDF is placed at `../risk_analysis_manuscript_latest.pdf`.
