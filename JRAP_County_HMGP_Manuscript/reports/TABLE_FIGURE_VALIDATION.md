The tables were regenerated by a script (`convert_tables.py`, kept in the session scratchpad; the logic is described here). It copies each `tabular` body **verbatim** and changes only the wrapper:
- `adjustbox` + `minipage` → `threeparttable` + `tablenotes`;
- "Note:" → "Notes:";
- a narrower, ragged-right label column in Tables 4 and 5;
- stacked header labels in Table 5 (same words);
- `\tabcolsep` 3.5pt in Tables 3, 5 and S1.

The following are retained exactly: coefficients, SEs, significance stars, means, N, cluster counts, FE rows, notes, column definitions and reference categories.

`siunitx` is loaded but not applied to the regression cells. Converting cells such as `$-8.79^{***}$ $(0.95)$` to `S` columns would mean rewriting each cell, and the risk of altering a displayed value outweighed the typographic gain.
